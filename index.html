Mashiro Small Theater

VRChat ワールド用ギミックの VPM リスティング

VCC に追加

うまく開かない場合は、VCC の Settings → Packages → Add Repository に次の URL を貼り付けてください。

https://meadowsage.github.io/mashirotheater-vpm/index.json

収録パッケージ

パッケージ内容依存
Mashiro Theater Common共有シェーダ・マテリアル・フォント・アイコン—
Mashiro Theater UtilsAutoDoor などの小規模ギミック詰め合わせCommon

依存は VCC が自動で解決します。Utils を入れれば Common も一緒に入ります。

マニュアル

各ギミックの使い方は マニュアル を参照してください。VCC のパッケージ詳細からも開けます。

すでに unitypackage 版を使っている場合

VCC でインストールすると、Assets/MashiroSmallTheater/ 配下の同じフォルダは 自動的に削除されます（legacyFolders による移行）。ファイルの GUID は変わらないため、 シーンやプレハブからの参照は維持されます。

念のため、インストール前にプロジェクトのバックアップを取ってください。
