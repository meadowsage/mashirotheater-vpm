# StageTimeline Builder — 高度な連携ガイド（Animator / Udon）

StageTimeline Builder では、シーンの進行に合わせて対象 Animator の状態を切り替えたり、
任意の Udon スクリプトの関数を呼んだりできます（いずれも「高度な機能を表示」を ON にすると現れます）。

## Animator 連携

用途に応じて 2 種類を使い分けてください。

| 種別 | 送るもの | 性質 | 代表的な使いどころ |
| --- | --- | --- | --- |
| **Animator パラメータ (Int)** | `SetInteger` | 状態（上書き・保持される） | 「State を 1 → 2 に切り替えて保持したい」 |
| **Animator トリガー** | `SetTrigger` | イベント（その瞬間に一度だけ発火） | 「特定の演出アニメを 1 回だけ再生したい」 |

Int は「今どの状態か」を保持し続けます。巻き戻すと過去時点の値に復元されます。
トリガーは「その瞬間に一度だけ」発火し、状態としては残りません（1 再生につき各発火は一度きり）。

## プリセットを登録する（プリセットタブ）

### Animator トリガー

1. 「Animator トリガー」セクションで **＋ Animator トリガーを追加**。
2. **Animator** に対象を割り当てます。
3. **送れる Trigger 一覧** に、その Animator へ送りたい Trigger を必要な数だけ登録します。
   - **Trigger 名**: AnimatorController に定義されている Trigger パラメータ名（`SetTrigger` に渡す名前）。
   - **表示名**: シーン側プルダウンでの表示名（省略時は Trigger 名を表示）。

1 つの Animator に複数の Trigger をまとめて登録しておき、シーンごとに「どれを送るか」を選ぶ運用です。

### 参照の仕組み

シーン側エントリは、選んだ Trigger を ID で参照します。

- プリセット側で **Trigger 名・表示名を変更**しても、シーン側の選択はそのまま追従します（再選択不要）。
- ID が失われている古いデータは、エントリが保持している Trigger 名が現在のプリセットにあれば自動で再接続されます。
- プリセットから **Trigger を削除した**場合や、**同名の Trigger が無いプリセットへ切り替えた**場合は
  「**[参照切れ — 再選択してください]**」表示になります。プルダウンから選び直してください
  （そのまま Generate するとそのエントリはスキップされ Console に Warning が出ます）。

## シーンで送る（シーンタブ）

1. 対象シーンの「Animator トリガー」で **＋ プリセット選択**（または **＋ 自由指定**）。
2. プリセットと、送る **Trigger** をプルダウンから選びます。
3. **遅延(秒)** を指定すると、シーン開始からその秒数後に送ります。

- **自由指定**: プリセットを使わず、Animator と Trigger 名を直接入力します。

## 生成時のチェックとスキップ条件

Generate 時に次を検証し、問題があればそのエントリを **スキップして Console に Warning** を出します
（古い設定のまま黙って動き続ける事故を防ぐため）。

- Animator が未設定
- Trigger 名が解決できない（プリセット側で Trigger が削除された／別プリセットに切り替えて参照が失効した）
- 対象パラメータが Trigger 型でない、または AnimatorController に存在しない

## 境界跨ぎ対策（リード時間）

シーン開始ちょうどで発火するトリガーが「前シーンの最終フレームで消費される」事故を避けるため、
発火はシーン開始より内側へ最低 0.1 秒ずらします（`AnimatorTriggerSceneStartLeadSeconds`）。
遅延をこれより大きく指定した場合は、指定値が優先されます。

## 生成される可視化トラック

Generate すると Timeline 上に `Animator Triggers` グループ（Animator ごとの muted トラック）が作られ、
各発火位置に `▶ <Trigger 名>` のマーカークリップが並びます。動作には影響しない確認用の表示です。

## Udon イベント連携

シーンの進行に合わせて、任意の `UdonSharpBehaviour` の関数を `SendCustomEvent` で呼べます。
Animator トリガーと同じ「一度きりのイベント」で、**再生ヘッドが指定タイミングを通過した瞬間に一度だけ**
発火します。シーン送り（Next）や途中参加で過去のタイミングを飛び越えた場合、そのイベントは
発火せずスキップされます（過去分のキャッチアップ再発火はしません）。

### 呼ばれる側の条件（重要）

- 呼べるのは **public・引数なしのメソッド** です（`SendCustomEvent` は引数を渡せません）。
- 発火は **各クライアントでローカル実行** されます。タイムラインは各クライアントでローカル再生され
  時刻同期されるため、全員が同じ時刻にローカル発火して演出が揃います。
  したがって呼ぶ関数は **全クライアントで実行されて安全なもの**（SFX 再生・アニメ再生など）にしてください。
- 対象オブジェクトが非アクティブだと Udon が動かない場合があります。

### Owner のみ実行（OwnerOnly）オプション

内部で `SendCustomNetworkEvent` を呼ぶ、あるいは Owner 権限を要する「1 人が起点になるべき関数」は、
全クライアントでローカル発火させると多重送信・競合を起こします。そうした関数には **OwnerOnly** を
ON にしてください。ON の場合、**対象オブジェクトの Owner のクライアントだけがローカル発火**します。

- **OFF（既定）**: 全クライアントがローカル発火。`local.TeleportTo` のようなローカル完結の処理向け。
- **ON**: 対象の Owner だけが発火。そこから内部で `SendCustomNetworkEvent(All)` 等を撒く前提の関数向け。

設定場所:

- **プリセットのイベント一覧**: 各イベント行の「Ownerのみ」チェックで宣言します。関数固有の性質なので
  ここで 1 度設定すれば、そのイベントを使う全シーンに自動適用されます（選択肢列挙型の追従）。
- **自由指定(Direct)**: エントリの「対象 Owner のみ実行」チェックで指定します。

> 例: `WarpEntrancePlayers`（各自が自分をローカルにテレポート）は OFF。
> `OnClickWarpEntrance`（内部で `SendCustomNetworkEvent(All)`）を呼ぶ設計にするなら ON。
> ただし原則は「ローカル完結版の関数を OFF で呼ぶ」方がシンプルで確実です。

### プリセットを登録する（プリセットタブ）

1. 「Udon イベント」セクションで **＋ Udon イベントを追加**。
2. **対象 Udon** に送信先の `UdonSharpBehaviour` を割り当てます。
3. **呼べるイベント一覧** に、呼びたい関数を必要な数だけ登録します。
   - **関数名**: `SendCustomEvent` に渡す public メソッド名。
   - **表示名**: シーン側プルダウンでの表示名（省略時は関数名を表示）。

1 つの Udon スクリプトに複数の関数をまとめて登録しておき、シーンごとに「どれを呼ぶか」を選ぶ運用です。

参照の仕組みは Animator トリガーと同じです。関数名・表示名を変更してもシーン側の選択は追従し、
ID が失われている古いデータはエントリが保持している関数名で自動的に再接続されます。
関数を削除した場合や、同名の関数が無いプリセットへ切り替えた場合は「参照切れ」表示になります。

### シーンで送る（シーンタブ）

1. 対象シーンの「Udon イベント」で **＋ プリセット選択**（または **＋ 自由指定**）。
2. プリセットと、呼ぶ **イベント** をプルダウンから選びます。
3. **タイミング** で「最初」（シーン開始時）か「最後」（シーン終了時）を選びます。
4. **遅延(秒)** を指定すると、シーン開始からその秒数後に送ります（「最初」のときのみ有効）。

- **自由指定**: プリセットを使わず、対象 Udon と関数名を直接入力します。

「最後」を選ぶと、そのシーンの終了直前（境界より手前）で発火します。次のシーンへ移る前に
確実に消費させたい処理（暗転前の後始末など）に使えます。

### 生成時のチェック

- 対象 Udon が未設定、または関数名が解決できない（プリセット側で削除／別プリセットへ切替で失効）
  エントリは **スキップして Console に Warning** を出します。
- 関数名が対象スクリプトに public・引数なしメソッドとして見つからない場合は **Warning のみ**（生成は継続）。
  存在しない関数を呼んでも実行時は無害なため、名前の打ち間違い検知の補助として通知します。

### 境界跨ぎ対策・可視化トラック

「最初」の発火はシーン開始より内側へ最低 0.1 秒ずらします（`UdonEventSceneStartLeadSeconds`）。
「最後」の発火はシーン終了より 0.1 秒手前にずらします（`UdonEventSceneEndLeadSeconds`）。
これにより境界ちょうどでの取りこぼし（前シーンの最終フレームで消費／シーン終了で取りこぼし）を防ぎます。
シーン尺がリード時間より短い場合は Warning を出し、発火をシーン先頭へ寄せます。

Generate すると `Udon Events` グループに Udon ごとの muted トラックが作られ、
各発火位置に `▶ <関数名>()` のマーカークリップが並びます。
