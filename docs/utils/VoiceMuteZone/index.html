Mashiro Voice Mute Zone

指定ゾーン内にいるプレイヤーの声を、他のプレイヤーへ聞こえなくするギミックです。舞台袖・楽屋などの「声を漏らしたくないエリア」に使います。

主な機能・仕様

  • ゾーン内のプレイヤーは、ゾーン外のプレイヤーから見て VoiceDistanceFar = 0 に設定され、声が聞こえなくなります。ゾーンを出ると既定値へ戻ります
  • ゾーン内どうしのプレイヤーは、互いに既定値のまま通常どおり会話できます
  • 除外ゾーンに入っているプレイヤーには、VoiceDistanceFar の既定値への復帰を行いません（他の音声系ギミックが設定した値を尊重するため）。ミュート自体の免除ではなく、ミュートゾーン内にいれば除外ゾーンにいてもミュートされます
  • 判定はプレイヤーの頭の位置で行います
  • 一定間隔（既定 1.5 秒）の位置チェックで判定します
  • 状態は Manual 同期で、Late Joiner にも反映されます。同期リストで扱えるゾーン内プレイヤーは最大 80 人です

ゾーンのコライダーは回転させないでください。 判定にはコライダーのワールド軸平行バウンディングボックス（AABB）を使うため、回転させると見た目の形と判定範囲がずれます。

セットアップ

MashiroVoiceMuteZone を任意の GameObject に付け、ゾーンのコライダーを割り当てるだけです。

フィールド 既定値 内容
Zone Colliders – ミュートゾーンのコライダー群（BoxCollider のみ・IsTrigger 必須・複数可）
Exclusion Zone Colliders – 除外エリアのコライダー群（任意・Collider なら種類は問わない）
Update Interval 1.5 秒 位置チェック間隔
Debug Text – エリア内プレイヤー名のデバッグ表示先（任意）

API リファレンス

MashiroVoiceMuteZone

public 関数は VRChat のイベントオーバーライドのみです。配線は不要で、Inspector の設定だけで動作します。
